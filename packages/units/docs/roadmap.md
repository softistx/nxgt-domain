# Roadmap

Where `@nxgt/units` is going. A direction, not a commitment: the version an
item shipped in is the only number on this page.

## Now

_Nothing in progress._

## Next

_Nothing queued._

## Later

- **A default unit set** — common mass, volume and length units as data.

## Not planned

- **Non-linear units** — an offset (degrees) is not a `Unit`; factors are
  linear only.
- **Recipes and bills of materials, persistence, API types** — they stay in
  the consuming application.

## Shipped

- **First release** — types, `round`, `convert`, `factorToBase` and
  `resolveQuantity` — 0.1.0.
